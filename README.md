# iOS App Archive

A GitHub Pages + GitHub Codespaces-ready web archive for classic iOS applications.

This project provides a searchable home screen containing app information, versions, bundle identifiers, supported iOS versions, and archive download entries.

## Features

- 📱 iOS app archive catalog
- 🔎 Search apps by name or Bundle ID
- 📦 IPA archive metadata display
- 🌐 GitHub Pages compatible
- 💻 GitHub Codespaces ready
- 🗂️ JSON-based app database support
- 📱 Mobile-friendly interface
